# Работа над ботом — памятка

Проект живёт в GitHub (**`ianreinit/zakupki-bot`**, приватный) — это единый
источник кода для всех устройств. «Боевой» бот крутится на сервере Hetzner
(`root@bertam.online`, служба `zakupki-bot`) и **сам подтягивает** свежий код с
GitHub (systemd-таймер `zakupki-autopull` каждые ~2 минуты).

Схема: **правишь код → коммит + пуш в GitHub → сервер обновляется сам.**

## Работа с любого устройства
- **С этого/другого Мака:** папка уже подключена к GitHub. Правишь → `./deploy.sh "что сделал"`.
- **С нового Мака:** `git clone git@github.com:ianreinit/zakupki-bot.git`, дальше как обычно (нужен доступ к GitHub на этом устройстве).
- **С телефона (через Claude):** правишь код и пушишь в GitHub — сервер сам обновится в течение ~2 минут. SSH к серверу с телефона не нужен.

## Ежедневный цикл
```bash
# 1) активировать окружение (один раз за сессию терминала) — для проверки синтаксиса
source venv/bin/activate

# 2) выкатить: коммит + пуш + мгновенное обновление сервера
./deploy.sh "коротко что изменил"

# 3) смотреть живой лог
./logs.sh
```
`./deploy.sh` сам делает `git add/commit/push` и просит сервер обновиться сразу.
Если просто `git push` без `./deploy.sh` — сервер подтянет изменения в течение
~2 минут по таймеру.

## Что где
- `main.py` — команды, кнопки, обработчики (approve/pay, /assign, /list…).
- `core.py` — создание заявки и рассылка карточек (директору/бухгалтеру/сотруднику).
- `webserver.py` — приём формы (мини-приложение), проверка подписи Telegram.
- `db.py` — SQLite (`zakupki.db`): заявки + реестр людей (`people`).
- `config.py` — сектора, настройки; секреты берутся из `.env`.
- `webapp/form.html` — сама форма заявки.

## Как устроен авто-деплой на сервере
- Папка `/opt/zakupki-bot` — это git-копия репозитория (тянет через отдельный
  deploy-ключ, только чтение).
- `/root/zakupki_autopull.sh` — тянет `origin/main`, при изменениях ставит
  зависимости и перезапускает службу.
- `zakupki-autopull.timer` — запускает скрипт каждые ~2 минуты.
- Лог деплоев: `ssh root@bertam.online 'cat /var/log/zakupki-deploy.log'`.

## Полезное на сервере
```bash
ssh root@bertam.online 'systemctl status zakupki-bot'      # статус бота
ssh root@bertam.online 'systemctl restart zakupki-bot'     # ручной перезапуск
ssh root@bertam.online 'systemctl start zakupki-autopull.service'  # обновить сейчас
```

## Важно
- **Не запускай бота локально (`python main.py`), пока он работает на сервере** —
  один токен = один процесс, иначе конфликт `getUpdates`.
- `.env`, `zakupki.db`, `venv/` в git не попадают (см. `.gitignore`) — они только
  на сервере, авто-деплой их не трогает.
- Старый способ деплоя (tar+scp) больше не используется — только через git.
- Полное развёртывание «с нуля» — в `DEPLOY.md`.
